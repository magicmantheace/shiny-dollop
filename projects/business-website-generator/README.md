# Small Business Website Generator

**Status:** PLANNED — project definition only; no working application is implemented by this intake commit.

**Priority:** 10 of 17 in the approved intake queue.
**Category:** Website authoring tool
**Repository workspace:** `projects/business-website-generator/`

## Purpose

Produce complete static websites for tradespeople, authors, restaurants, and independent businesses.

## First usable release (MVP)

Choose a business type, fill contact/services, preview a responsive website, and export a deployable static folder.

## Full intended capabilities

- Trade/author/restaurant starter layouts
- Theme and business-profile forms
- Home/services/contact and optional menu/pages
- SEO metadata and sitemap
- Accessible navigation and form alternatives
- Mobile preview and responsive layout
- Validated static package export

## Proposed implementation direction

Standalone local editor, original responsive HTML/CSS themes, static export; no hosting required. Muse must confirm feasibility before committing to framework choices.

## Dependencies and boundaries

Optional import of versioned templates from Digital Product Template Factory.

One-time purchase model; no recurring paid upgrades; do not include copyrighted brand imagery or unlicensed templates.
