# Muse implementation handoff — Small Business Website Generator

**Priority:** 10/17. **Project:** `projects/business-website-generator/`.
**Status:** Project documentation is created; application code has not yet been implemented.

## Assignment

Produce complete static websites for tradespeople, authors, restaurants, and independent businesses.

### Start here

1. Read repository-root `AGENTS.md` and this project's `AGENTS.md`.
2. Inspect the latest `main` and all relevant unmerged branches/PRs. Do not overwrite someone else's work.
3. Begin a dedicated `business-website-generator/mvp` branch once this intake has been merged (or base appropriately without rewriting history).
4. Choose the simplest maintainable stack compatible with: Standalone local editor, original responsive HTML/CSS themes, static export; no hosting required.
5. Implement the **actual** MVP: Choose a business type, fill contact/services, preview a responsive website, and export a deployable static folder.
6. Write automated tests for its success path and critical failure modes. Execute `docs/TEST_PLAN.md` where the environment permits.
7. Commit scope-limited production code, validate the build, and open an unmerged PR documenting evidence and limitations.
8. Update `docs/IMPLEMENTATION_STATUS.md`; do not claim unverified capabilities work.
