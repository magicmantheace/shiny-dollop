# android/ — Kotlin companion app (P4, planned)

Placeholder for slice P4. Nothing here yet.

The Android app (Kotlin + Jetpack Compose) will be a thin client of
the desktop pet's companion server: connection setup (address +
pairing token), a status screen (sprite, needs bars, stage/mood), and
care action buttons. It contains **no** simulation and no
authoritative pet state — the pet lives on the PC. Protocol draft:
`../docs/DESIGN.md`.
