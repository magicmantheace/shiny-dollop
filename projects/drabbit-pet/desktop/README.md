# desktop/ — Electron desktop pet (P2/P3, planned)

Placeholder for slices P2 and P3. Nothing here yet.

- **P2** will add the Electron + React + TS desktop pet: transparent
  always-on-top window, sprite states driven by `core/`, click-open
  care panel, tray icon, save-file ownership, offline catch-up on
  launch.
- **P3** will add the token-authenticated companion server the Android
  app talks to (protocol drafted in `../docs/DESIGN.md`).

The desktop app is the only writer of the pet's save. See
`../docs/MUSE_HANDOFF.md` for slice status.
